# Whole-Repository Theory Map

## Governed object

A learning transition is a change from learner state `L_t` to `L_(t+1)` through the ordered stages:

`Exposure -> Attention -> Interpretation -> Model Formation -> Action or Expression -> Feedback -> Revision -> Responsibility`.

The repository distinguishes a measured change from an admissible development. A change is not sufficient evidence of learning, and learning is not sufficient evidence of authority.

## Doctrine layers

1. `general/` defines the shared transition structure and the principle of maximizing becoming without capture.
2. `human/` specializes the structure for human agency, consent, responsibility, identity, and developmental context.
3. `artificial-intelligence/` specializes the structure for model updates, training, evaluation, feedback, and bounded system behavior.
4. `data/learning-stages.json` provides the canonical stage vocabulary.
5. `data/learning-outcomes.json` provides the bounded outcome vocabulary.
6. `tools/check_learning_stages.py` and `tools/check_learning_outcomes.py` validate repository-local structural conformance.
7. `formalism/` records principles, dependencies, proof candidates, falsifiers, and non-authority boundaries.

## Evidence flow

A claimed learning transition requires an identifiable pre-state, exposure or input, observable action or expression, feedback, revision evidence, and a bounded outcome classification. Missing evidence produces `INSUFFICIENT_EVIDENCE`; detected capture produces `CAPTURE_RISK`; an inadmissible transition remains distinguishable from measured change.

## Authority boundary

Repository-local validation proves only that declared data and formalism conform to this repository's contract. It does not prove AE admissibility, learner consent, execution authority, publication authority, certification, release readiness, or universal validity.

## Cross-repository integration

Consumers must import hash-bound artifacts through separately admitted tasks. Human and AI specializations may share vocabulary but must not inherit one another's identity, consent, delegation, accountability, or execution authority.
